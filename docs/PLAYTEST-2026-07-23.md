## Fixed this session
- **#14** declined AGM call-up no longer re-pitched the same season (persisted `declinedCallups` ledger; save-safe).
- **#25** mid-season retirement announcements on load suppressed.
- **#19a** xG/creation scatter fixed. xA ("expected assists") accrued only on
  GOALS, so it was ≈ real assists (sparse) while xG accrued on every shot —
  every dot piled at the low-creation edge. Now xA credits the deterministic
  top-playmaker on the ice on EVERY shot (no rng draw → byte-identical replay),
  mirroring xG. Playmakers now spread right, snipers stay top-left, grinders
  low-both — a real 2D distribution. Both sims; 86 determinism/parity tests green.
- **#19b** playoff odds "stuck at 4%": NOT a bug — the Monte-Carlo recomputes
  daily (seed + base points both key off the day) but projects remaining games
  from ROSTER STRENGTH, so an 8-4 club with a weak imported roster genuinely
  projects to fade. Statistically sound; feels bad when overperforming. A
  calibration/feel call (weight recent form? cap early-season strength
  dominance?) — left for the user, not blind-tuned.
- **#19c FIXED** — scatter readability. Overlapping dots now walk a small
  deterministic spiral to clear ice (no rng, stable across renders), every dot
  carries an oversized invisible hit circle (hover/click no longer needs pixel
  hunting), non-user dots drop to 80% fill so pile-ups read as density, and both
  scatter panels gained an **Expand** button opening a full-width modal (1060px
  plot, Esc/backdrop/× to close) where the decluster has room to separate the
  pack. App-verified in season: all four quadrants populated and individually
  labelled.
- **#2b FIXED** — the processing overlay's mini calendar reached parity with the
  real one: opponent crest + abbreviation with H/A marking, whole-cell W/L tint
  plus W · W·OT · OTL · L, a cyan ring + "Next" on the next fixture, amber
  key-date dots, and per-cell hover titles (opponent, score, key-date labels).
  Was two anonymous dots on an otherwise empty grid.
- **Harness** — `ui-snapshot.mjs advanceOnce` now tries EVERY match of each
  button selector (last first) instead of only match #0. That was the
  free-agency stall: on an eventful FA day the topbar "Continue — …" is match #0
  but sits UNDER the processing overlay's backdrop (click times out), while the
  overlay's own Continue — the button that actually advances — was never tried.
  The harness now reaches the regular season.

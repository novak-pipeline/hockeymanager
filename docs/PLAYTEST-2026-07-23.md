## Fixed this session
- **#14** declined AGM call-up no longer re-pitched the same season (persisted `declinedCallups` ledger; save-safe).
- **#25** mid-season retirement announcements on load suppressed.
- **#19a** xG/creation scatter fixed. xA ("expected assists") accrued only on
  GOALS, so it was ≈ real assists (sparse) while xG accrued on every shot —
  every dot piled at the low-creation edge. Now xA credits the deterministic
  top-playmaker on the ice on EVERY shot (no rng draw → byte-identical replay),
  mirroring xG. Playmakers now spread right, snipers stay top-left, grinders
  low-both — a real 2D distribution. Both sims; 86 determinism/parity tests green.
- **#19b** playoff odds "stuck at 4%": NOT a bug — the Monte-Carlo recomputes
  daily (seed + base points both key off the day) but projects remaining games
  from ROSTER STRENGTH, so an 8-4 club with a weak imported roster genuinely
  projects to fade. Statistically sound; feels bad when overperforming. A
  calibration/feel call (weight recent form? cap early-season strength
  dominance?) — left for the user, not blind-tuned.
- **#19c** scatter still needs UI love (dots clustered / no expand) — the
  clustering was mostly the xA bug; revisit readability after playtesting.
